CORSO MOTORS — PRODUCTION PACKAGE

ГОТОВО:
• Адаптивный премиальный сайт.
• 14 позиций автопарка с ценами.
• Фильтры и онлайн-форма бронирования.
• Расчёт ориентировочной стоимости по датам.
• Кнопка WhatsApp с автоматически сформированной заявкой.
• События Meta Pixel: PageView, ViewContent, Lead, Contact.
• Google tag и события для Google Ads.
• Подготовлено к подключению собственного домена.

ПЕРЕД ПУБЛИКАЦИЕЙ:
Откройте index.html и замените в CORSO_CONFIG:
whatsappNumbers: ["77752326443", "77007776626"] — два номера WhatsApp. Сейчас кнопка бронирования открывает первый номер; контактный блок содержит кнопки обоих номеров.
metaPixelId: "META_PIXEL_ID" — ID Meta Pixel.
googleTagId: "AW-4549659629" — уже установлен указанный вами Google ID.

ФОТО:
Замените визуальные блоки .car-image на реальные фотографии автомобилей. Лучше использовать WebP/JPG и отдельную фотографию для каждой машины.

ДОМЕН:
Загрузите index.html, styles.css и script.js в корень сайта на вашем хостинге. После этого домен можно привязать к папке сайта.

АНАЛИТИКА:
Google рекомендует размещать Google tag на всех страницах и использовать conversion events для ценных действий; здесь событие Lead отправляется при отправке формы, а Contact — при переходе в WhatsApp.
